# 📊 Customer Churn Prediction System

An end-to-end Machine Learning web application designed to predict customer churn in the telecom industry and provide actionable retention insights.

Built with **Python**, **Scikit-Learn**, **Streamlit**, and **Plotly**.

---

## 🚀 Key Features

- **Real-Time Churn Prediction:** Predicts whether a customer is likely to stay or leave with probability and confidence scores.
- **Interactive Risk Gauge:** Visualizes churn probability across calibrated tiers (Low, Medium, High Risk).
- **Directional Feature Importance:** Highlights top factors driving churn vs. factors supporting retention.
- **Dynamic Input Validation:** Prevents conflicting data entry (e.g., internet services vs. no internet).
- **Session Analytics Dashboard:** Live tracking of analyzed customers, churn rate, and contract-wise distributions.
- **PDF Report Generation:** One-click download of comprehensive customer retention advisory reports.
- **CSV Prediction Log:** Export batch session predictions for business analysis.

---

## 🛠️ Tech Stack

- **Machine Learning:** Scikit-Learn (`LogisticRegression`, `StandardScaler`)
- **Web App / UI:** Streamlit
- **Visualizations:** Plotly Express & Plotly Graph Objects
- **Document Generation:** ReportLab
- **Data Manipulation:** Pandas, NumPy



3. **Launch the Streamlit app:**
